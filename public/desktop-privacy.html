Ref-OS Connect Privacy Policy

Updated November 2, 2026. Operated by Maharshi Patel / Ref-OS. Contact: refos.app@gmail.com.

Purpose and information used

Ref-OS Connect combines Tournament Manager (TM) connection and a local venue server for VEX events. You choose the Ref-OS website and TM server. The app processes event access credentials, your volunteer profile and contact information if provided, team and match data, rankings, Skills, live field activity, violations, nominations, notes, and robot photos as you use those features.

Where information goes

TM requests read from the selected local TM server. When you use Cloud mode, event information and authentication are sent to Ref-OS Cloud (Supabase) so authorized event users can share updates. Ref-OS website traffic uses the website you selected. In Venue Server mode, supported shared records are stored on the host computer and sent to devices connecting to that venue server. Local venue records are not automatically copied to Cloud. Network addresses and device presence are used for connectivity and host diagnostics.

Storage and controls

The app saves website preferences and local venue records on this computer. TM API keys are kept in memory during the connection and are not included in the venue backups. The venue server saves local backups every five minutes while running and retains the latest 24. Exported backups remain wherever you save them. Stop Server ends local sharing; sign out or disconnect ends the relevant session. Authorized administrators manage shared event records in Ref-OS. Contact support for questions or deletion requests. Export data you need before uninstalling or deleting app data; do not assume uninstalling removes cloud records or exported backups.

Sharing and security

We do not sell personal information, use it for advertising, or use it for credit or lending decisions. Event information is shared with authorized event participants and the hosting providers needed to operate Ref-OS. Local venue connections may use unencrypted HTTP on your venue network; use a trusted event network and restrict access to event staff. No separate advertising or analytics SDK is bundled in the desktop connector.

Permissions

The desktop app runs with normal user privileges to connect to local TM servers, host a local TCP server, save local records and backups, and display its interface and tray controls. Windows may ask you to allow venue network access. The server runs only when you start it and can be stopped in the host window or tray.

Changes

We update this page when these practices change. For support or privacy questions email refos.app@gmail.com.
