Ref-OS Connect Privacy Policy

Updated November 3, 2026. Operated by Maharshi Patel / Ref-OS. Contact refos.app@gmail.com.

Purpose and information used

Ref-OS Connect for Android connects Tournament Manager (TM) to Ref-OS and can host a local venue server. When you use event features, the app processes event access credentials, volunteer names and profile information, contact information you provide, team and match data, rankings, Skills, live field activity, violations, nominations, notes, and robot photos. Network addresses, device identifiers used for event sessions, and connection status support sharing and diagnostics.

Where information goes

TM requests read from the TM server you choose using its event API key. Cloud mode sends authentication and event information to Ref-OS Cloud, hosted using Supabase, so authorized event users can share updates. Ref-OS website requests go to the selected website and its service providers. In local venue mode, supported shared event records are stored on the Android host and sent to devices connecting to that server. Local venue records are not automatically copied to the cloud.

Storage, retention, and deletion

The app stores preferences, session information, and local venue records on your device. TM connection keys are kept in memory during the connection. While the venue server runs, it saves backups every five minutes and retains the latest 24. Exported backups remain in the location you select. Stop Server ends local sharing; disconnecting or signing out ends the relevant session. Clearing app data or uninstalling removes local app records, but does not remove cloud records or exported backups. Export records you need before uninstalling. Authorized event administrators manage shared event records. To request deletion of information held by Ref-OS, email refos.app@gmail.com and identify the event and information concerned; we may need to verify your authority before deleting shared records.

Request deletion of your profile, account, or data

Email refos.app@gmail.com with the subject “Ref-OS Connect deletion request”. Include the event name and the volunteer nickname or profile you used. Specify whether you want your profile and associated account/session deleted, or only particular records removed. Do not send your event passcode or TM API key. We will verify the request and explain any shared event records that must remain with the event administrator.

Verified deletion requests cover the associated volunteer profile/contact information and account/session identifiers held by Ref-OS. Shared match records, violations, nominations, and other event records may also concern other participants and are handled with the event administrator; we will identify records retained and the reason in our response. Local host records and exported backups are controlled by whoever hosts or saves them. Contact that host to remove those copies. Automatic local backups rotate after the latest 24 snapshots; exported copies are not automatically removed. Deleting cloud information cannot remotely erase independently exported copies.

Sharing and security

Event information is shared with authorized event staff and service providers needed to operate Ref-OS. We do not sell personal information or use it for advertising, credit, or lending decisions. Ref-OS cloud connections use HTTPS. Local TM and venue connections may use unencrypted HTTP on your network. Use a trusted event network and restrict access to authorized staff. The native connector does not bundle advertising or analytics SDKs.

Android permissions and controls

Network access enables TM connections, website access, and venue hosting. Network-state permissions and a wake lock support hosting. The venue server uses a foreground service and notification so it can continue running while you switch screens. Start Server begins hosting; Stop Server ends it. Force-stopping the app or restarting Android also stops hosting. When you choose to export a backup, Android lets you select where to save it. Photo or file selection in event features is initiated by you and may use Android or browser permission prompts.

Changes and contact

We update this page when these practices change. For support, privacy questions, or deletion requests, contact refos.app@gmail.com.
