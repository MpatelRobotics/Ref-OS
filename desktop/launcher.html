Ref OS TM Connect

Share Tournament Manager updates with your Ref OS event.

Use the same website you normally open for Ref OS.

    1. Sign in and select your event.
    2. Enter the TM server address and event API key.
    3. Select one division or both TM divisions, review the data and start syncing.

    This computer must reach TM and the internet. Switching Ref OS divisions keeps both syncs running. Once syncing starts, closing the window keeps it running in the system tray. Other event users can follow updates from anywhere.
