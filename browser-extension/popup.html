Ref OS TM Connect

Allow the TM server used by your event. Connect this computer to the TM network.

Then open TM Sync Center in Ref OS. Your server address and API key will be filled in automatically. Live fields, teams, matches, scores, rankings and Skills sync through this extension. Keep the Ref OS tab open.

The server address is saved. The API key is kept only until Chrome closes. School IT may need to approve this extension.
