Run this app on one Windows computer. Other devices connect through their browser.

Connect phones and tablets

  1. Connect every device to the same Wi-Fi as this computer.
  2. On each device, enter one of these addresses in Server URL in Ref OS, then tap Open Ref OS at the venue address. You can also type the address directly into its browser.
  3. Sign in while internet is available. Add a sample violation and check that another device sees it.

Keep this app open and this computer awake. If another device cannot connect, check Windows Firewall and ask venue IT whether the Wi-Fi allows devices to communicate.

Where is my data saved?

Stopping the server keeps your data. Local records do not upload to Cloud automatically. Use Export Venue Data in Ref OS before switching back to Cloud.
